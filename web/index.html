    M-Flasher + for the web
    
          
    Back up, restore and install firmware on an M-VAVE FM-1 or SMK-37 from a browser, over USB MIDI, with the community firmware library. An experimental beta: it has had far less testing than M-Flasher + on a computer. Save a backup first.
    
          
    How it reaches the unit. A browser can't use the chip's download mode, so this page works through MIDI: with m-bootloader, hold PLAY (SEQ PLAY on the SMK-37) at power-on and choose MIDI MODE; with normal firmware running, START THE TOOLS sends a small helper through the firmware's own update route, which runs from RAM and goes back to the firmware afterwards. The boot area, the key area, and the SMK-37's calibration and Bluetooth data are never written from here.
    
          
    Where the firmware comes from. The list of firmwares is The Firmware Hub's, used as an index. Each package is fetched from its author's GitHub: files in a repository directly, release files through this site, because GitHub doesn't let a page read them. Either way the SHA-256 the list gives is checked before anything is written.
    
          
    What stays with you. Backups go to your downloads. Nothing about you or your unit is sent anywhere.
    
          
    You still need M-Flasher + on a computer for a unit that won't start and has no m-bootloader, and to put the stock bootloader back.
    
          
    M-Flasher + is maintained by Wellington Saam: questions and bug reports go to its issues. Based on M-Flasher by Julius Vitkauskas (MIT), who does not support this version. Bootloader and helper: m-bootloader (MIT). Each firmware belongs to its author, under its own license.

Every write is checked by the unit before anything is erased, but use it at your own risk.
