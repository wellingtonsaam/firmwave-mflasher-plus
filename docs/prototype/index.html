Try it

  1. Check the FM-1DEVICE › CHECK FM1 STATUS. It switches the unit to download mode and reads it.
  2. Get a firmwareLIBRARY › GET. Downloaded from the author's release and checked by SHA-256.
  3. Install it on the stock bootloaderm-bootloader goes first, in two reviewed steps.
  4. See its real namezp12 shows up as "zp12 2.5 · Felucca", on DEVICE INFO, on the FM-1 and in BACKUPS.
  5. Try a newer FM-1Pick "Newer chip (2026)" and check it. In LIBRARY, turn off "This unit only" and INSTALL Hortator.
  6. Open the Android appSame core, same tabs, over a USB OTG cable.

Prototype: the FM-1 is simulated. Nothing is connected, downloaded or written. The real app: github.com/wellingtonsaam/m-flasher-plus. Based on M-Flasher by Julius Vitkauskas. Firmware list: The Firmware Hub (CC BY 4.0).
